# Capstone Project 2 - Terraform S3 Static Website

## Overview
This project deploys a publicly accessible static website using Amazon S3 and Terraform.

## Resources Created
- Amazon S3 bucket
- S3 bucket ownership controls
- S3 public access configuration
- Public bucket policy
- S3 static website hosting
- index.html uploaded using Terraform

## Deployment
```bash
terraform init
terraform validate
terraform plan
terraform apply
