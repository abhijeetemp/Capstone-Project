# Project 10 - Internal DNS Setup

## Goal
Access a server using a hostname instead of an IP address.

## Tasks Completed
- Configured DNS Server.
- Created an A record for webserver.capstone.local.
- Mapped hostname to IP address 10.5.3.122.
- Verified DNS resolution using nslookup.

## Verification
Hostname: webserver.capstone.local
IP Address: 10.5.3.122

Command used:
nslookup webserver.capstone.local

## Result
DNS hostname resolution successfully verified.
